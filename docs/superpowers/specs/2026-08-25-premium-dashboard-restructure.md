# 高级化零删减 Dashboard 重构规格

## 目标

在不删除当前任何页面入口、指标、字段、筛选、交互或管理操作的前提下，重构 cpa-usage-dashboard 的嵌入式前端，使其呈现为高密度、层级清晰、视觉克制的 CLIProxyAPI 可观测性控制台。

## 不可删减的内容契约

### 全局壳层

以下内容必须继续存在并可操作：

- 品牌标识“用量 Keeper”和“CLIProxyAPI”。
- “总览”“接口”“设置”三个页面入口。
- 管理连接状态和在线/中断状态。
- 页面标题和副标题。
- “24 小时”“7 天”“30 天”“全部”四个范围选项。
- 手动刷新按钮。
- CPA 宿主主题同步，不保存插件自己的主题偏好。

### 总览页

#### KPI

必须保留以下 7 组 KPI 及其全部子指标：

- 日均用量：日均请求、日均 Token、日均费用、统计范围。
- 总请求数：总数、成功数、失败数、成功率、请求 sparkline。
- 总 Token 消耗：总 Token、缓存读取、缓存写入、推理 Token、Token sparkline。
- RPM：每分钟请求、总请求数、请求 sparkline。
- TPM：每分钟 Token、总 Token、Token sparkline。
- 缓存命中率：命中率、缓存读取、输入 Token、命中率 sparkline。
- 总费用：费用、总 Token、费用 sparkline。

#### 趋势图

必须保留：

- 输入、输出、缓存创建、缓存读取、缓存命中率五个可选系列。
- 图例选中/取消选择状态。
- Token 左轴和命中率右轴。
- 时间轴、空数据状态、平滑曲线、缓存区域填充。
- 鼠标吸附、参考线、当前点高亮和 Tooltip。
- Tooltip 中的实际费用和标准费用。
- 只使用内存中的已加载趋势点完成图例切换，不新增请求。

#### 服务健康监测

必须保留：

- 中国时区 Asia/Shanghai。
- 最近 5 个自然日。
- 每日 96 个 15 分钟格子。
- 成功率、成功数、失败数。
- 异常到健康的颜色等级和无请求灰色状态。
- 单元格时间、请求数、成功/失败、成功率 Tooltip。
- 复用 480 个 DOM 单元格的低负载更新策略。

#### 分析区

四个分布必须继续展示：

- 模型分布。
- 上游分布。
- 客户端 Key 分组。
- 渠道来源分布。

每个分布至少保留当前 Top 5、请求数、请求占比、名称脱敏/合并规则、环形图与列表联动 Tooltip。视觉形式可以分别升级为环形图、排名条、健康条和负载条，但不减少统计项。

#### Token 构成

必须保留：

- 总 Token。
- 输入、输出、缓存读取、缓存写入、推理五类构成。
- 堆叠比例条。
- 五项图例、数量、占比。
- 悬停高亮、Token Tooltip 和固定查看交互。

#### 模型统计

必须保留以下列：

模型、请求、成功率、缓存命中率、Token、平均延迟、费用。

命中率进度条和 Token 的 K/M 格式必须继续存在。

#### 运行时状态

必须保留：

- 队列深度 / 容量。
- 已接收。
- 已写入。
- 已丢弃。
- 最近批写耗时。
- 存储错误 Toast。

可补充现有 API 已提供但当前未显式展示的批大小、写入失败、保留天数和最后写入时间，但不得替换上述五项。

#### 请求明细

必须保留：

- 搜索。
- Provider、模型、状态筛选。
- 筛选、重置、CSV 导出。
- 总记录数、分页、上一页、下一页。
- 时间。
- 模型 / 渠道。
- 推理强度。
- 状态与失败信息。
- Token 明细中的非缓存输入、输出、缓存读取、缓存创建、思考/推理、总 Token。
- 缓存命中率。
- 总 Token。
- 不重新展示端点。

Token 明细可以使用紧凑的双行单元格，但完整字段必须通过同一行的可见摘要、Tooltip 或键盘可固定详情访问。

### 接口页

必须保留：

- 客户端 Key 凭证数量。
- 上游通道集群数量。
- 接口总请求量。
- 上游平均响应延迟和健康数量。
- 客户端 Key 分组表：Key、绑定模型、调用次数与占比、成功率、Token、预估费用。
- 上游统计表：上游分组名称、状态、关联模型、负载请求占比、成功率、平均延迟、Token、详情操作。
- 上游详情抽屉：名称、请求、成功率、Token、平均延迟、模型请求列表、近期事件列表。

### 设置页

必须保留：

- SQLite/内存存储路径。
- 保留天数。
- 导出上限。
- 数据库大小、事件数、Rollup 数、队列丢弃数。
- 模型价格表的模型、输入、输出、缓存读取、缓存写入、推理价格。
- 添加模型、删除模型、保存价格。
- 备份导出和备份导入。
- Management Key 当前会话状态和更新密钥。

## 视觉与交互方向

- 定位为高级运维/可观测性控制台，不使用营销式 Hero、装饰性插画、渐变光球或大面积模糊背景。
- 采用中性画布、三层表面、细边框和少量语义色；蓝、紫、青、绿、橙、红分别对应业务含义，不让单一色相占据整页。
- 普通区块使用平面分组和分隔线，卡片只用于 KPI、重复统计项、抽屉指标和真正需要框定的工具。
- 统一 8–12px 圆角、12–24px 内容间距、10–15px 辅助文字、14–18px 区块标题。
- 数字使用 font-variant-numeric: tabular-nums；Token 使用 K/M，完整值通过 title 或 Tooltip 提供。
- 主题只读取 CPA 宿主的 data-theme / data-cpa-theme，通过 MutationObserver 同步，不轮询、不写入插件主题存储。
- 交互反馈优先采用颜色、边框和局部高亮，减少所有面板统一上浮造成的视觉噪声。
- 页面主体和事件明细不出现无意义的整体横向滚动；图表保留全部数据点，只减少轴标签密度。
- 触摸、键盘、prefers-reduced-motion 和高对比度模式均可用。

## 具体视觉规范

### 背景与表面

浅色主题使用三层中性表面：

| 层级 | 颜色 | 用途 |
| --- | --- | --- |
| 页面画布 | `#F4F6F9` | body、页面空白区域 |
| 一级表面 | `#FFFFFF` | 主要区块、表格、设置编辑区 |
| 内嵌表面 | `#F7F9FC` | 表头、筛选输入、telemetry rail、次级信息 |
| 凹入表面 | `#EEF2F7` | 图表绘图区、禁用状态、无请求格子 |

深色主题对应为 `#0F141B`、`#151C26`、`#1B2430`、`#222D3A`。背景不使用渐变、纹理、光球或大面积半透明装饰；层级通过表面差、1px 边框和留白表达。

页面内容最大宽度为 1440px，左右内边距桌面端 32px、平板 20px、手机 14px。顶部应用栏固定高度 64px，使用不透明主题表面和底部边框，避免滚动时内容透过造成文字干扰。

### 字体与数字

字体栈固定为 `Inter, PingFang SC, Microsoft YaHei, Noto Sans SC, system-ui, sans-serif`；数字和 Token 明细使用 `SFMono-Regular, Consolas, Liberation Mono, monospace`。

| 元素 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 页面标题 | 28px | 760 | 1.2 |
| 区块标题 | 16px | 720 | 1.3 |
| 卡片标题 | 13px | 680 | 1.35 |
| 正文和表格 | 13px | 500–620 | 1.45 |
| 辅助说明、表头、标签 | 10–11px | 620–680 | 1.35 |
| KPI 主值 | 28–32px | 760 | 1.1 |

所有 KPI、请求数、Token、百分比、延迟、价格启用 `font-variant-numeric: tabular-nums`；不使用负字距，不随视口缩放字号。Token 统一 K/M，完整数值通过 `title` 或 Tooltip 提供。

### 颜色语义

| 语义 | 浅色值 | 深色值 | 用途 |
| --- | --- | --- | --- |
| 主强调 | `#326FF5` | `#6F9BFF` | 导航激活、输入、链接、焦点 |
| Token/模型 | `#7738EE` | `#A98BFF` | Token 总量、模型排名 |
| 成功/健康 | `#20B95A` | `#42D982` | 成功率、在线状态、输出 |
| 缓存读取 | `#18AD9D` | `#39D1C0` | 缓存读取、命中率辅助 |
| 缓存创建 | `#E88419` | `#FFB35C` | 缓存创建、批写提示 |
| 失败/异常 | `#D94A4A` | `#FF7B86` | 失败、丢弃、错误 |
| 警告/费用 | `#B27A08` | `#F4C45E` | 费用、波动、延迟警告 |

图表固定映射为：输入蓝色、输出绿色、缓存创建橙色、缓存读取青绿色、缓存命中率紫色虚线；同一语义在 KPI、图表、表格和 Tooltip 中不更换颜色。

### 排列与尺寸

- 总览使用 12 列逻辑网格；KPI 第一行占 4/4/4 列，第二行四个卡片各占 3 列。
- 趋势与健康使用 8/4 列；趋势图最小绘图区高度 320px，健康网格保持 96 × 5 的数据密度。
- 四个分布桌面端四列、1280px 以下两列、680px 以下单列；每种分布使用不同视觉编码但共享标题和内边距。
- Token 构成使用 8/4 列；模型表和请求明细使用完整宽度。
- 普通区块圆角 10px，重复统计卡片 12px，抽屉 16px；边框统一 1px，普通区块无阴影，重点卡片只使用 `0 2px 8px rgba(24,34,53,.05)`。
- 区块间距 24px，区块内部 18px，控件间距 10px；表格行高 46px，紧凑事件行最小高度 58px。
- 表格标题、数字和操作列建立固定列宽与基线；长模型名、Provider 和 Key 使用省略号并保留 title。

### 状态与动效

- 激活导航使用主色文字、浅色底和 2px 底部指示线，不使用大面积渐变。
- Hover 只改变边框、背景或局部透明度，不让整页所有区块同时上浮。
- Focus ring 为 2px 主色外圈加 2px 间距；颜色状态同时有文字，不能只靠颜色区分。
- 页面进入、图表首次绘制和进度条动画不超过 220ms；自动刷新不重复播放页面进入动画。
- prefers-reduced-motion 下关闭 transform、路径动画和 shimmer。

## 数据与性能边界

- 不修改 Go 管理 API 路径、JSON 字段、SQLite schema、备份格式或 ABI。
- 不增加 usage 采集路径上的工作。
- 不增加总览刷新所需的 API 请求数量；继续按 summary -> analysis -> events 分阶段加载。
- 图例、分布悬停、Token 悬停、主题变化只更新前端视图。
- 保留 60 秒自动刷新、页面可见性判断、前端缓存 TTL、AbortController 和请求 ID 防竞态。
- 不引入第三方图表库、CSS 框架或外部字体。

## 验收条件

- 内容契约中的每个项目在 HTML/JS 静态断言和浏览器检查中都能找到。
- 1440×900、1280×800、1024×768、768×1024、390×844 五种视口均无内容丢失。
- 图例切换、分页、筛选、导出、上游详情、价格保存、备份导入导出、Management Key 对话框功能不回归。
- go test ./...、node --check go/dashboard/app.js 通过。
- CSS 选择器无重复残留导致的覆盖不确定性，括号配对，旧 .sidebar 和插件主题切换残留全部清理。
